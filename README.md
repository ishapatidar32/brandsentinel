# BrandSentinel — deploy-ready demo

React/Vite frontend + Express 5 API + MongoDB. Submission checks use deterministic demo rules; they are not legal advice or a live fact-checker.

## Deploy in Render (single public URL)
1. Push this folder to a GitHub repository (do not commit `.env` or credentials).
2. In Render choose **New → Blueprint**, connect the repository, and apply `render.yaml`.
3. In the service environment, set `MONGO_URI` to a MongoDB Atlas connection string. Atlas must allow Render network access (for a fast demo, `0.0.0.0/0`, with a strong database password).
4. Deploy. `JWT_SECRET` is generated by Render. The service health endpoint is `/health`.
5. After first deploy, open the Render Shell and run `npm run seed --prefix server` once to create the demo accounts and brand kit. Demo password: `Demo123!` for creator/reviewer/admin accounts listed on the login page.

## Local
- Install Node 20+ and MongoDB (or Atlas).
- Copy `server/.env.example` to `server/.env`, set `MONGO_URI` and a random `JWT_SECRET`.
- `npm run install:all`, then `npm run seed`, then `npm run dev`.
- Frontend: `http://localhost:5173`; API health: `http://localhost:5000/health`.

Never use the included demo credentials or permissive database access for production. The app is configured for a demo submission.
